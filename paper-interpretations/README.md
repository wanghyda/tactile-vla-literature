## Interpretation convention

Each document separates:

- **Paper facts**: claims, configurations, equations, and results explicitly reported by the paper.
- **Technical analysis**: interpretation of novelty, improvements, accumulated knowledge, assumptions, limitations, and reproducibility risks.

The documents link to the corresponding arXiv version, HTML source, LaTeX source, and official project page where available. They do not redistribute paper PDFs.

## Maintenance rule

Every future paper interpretation must be added to this directory and linked from
this README, the repository README, the relevant topic page, `papers/index.csv`,
and `sources/references.bib` in the same change before it is pushed to GitHub.
